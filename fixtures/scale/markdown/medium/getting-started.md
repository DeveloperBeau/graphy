# Getting started

Install abacus from your package manager, then start it with no
arguments. You get a prompt; type an expression and press enter:

    > 12 * (3 + 4)
    84

## Reading the prompt

The prompt shows the current angle mode and precision, so `deg:12>` means
degrees with twelve significant digits. Both are covered in
[precision and rounding](precision.md).

Continue with the [expression syntax](expressions.md), or jump straight
to the list of [built-in functions](functions.md).
