# The sqrt function

Reference for `sqrt`, one of the built-ins listed in
[built-in functions](functions.md).

## sqrt usage

`sqrt(x)` evaluates immediately and lands on the tape like any other
entry. Argument errors raise `domain error`, described in
[error messages](error-messages.md).

## sqrt precision

Results carry full internal precision and round only at display time,
per [precision and rounding](precision.md).
