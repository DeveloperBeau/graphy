# FAQ

## Why twelve display digits

Enough for most engineering work while keeping columns narrow; raise it
per session as shown in [precision and rounding](precision.md).

## Can abacus plot

No. Pipe the tape export from [exporting the tape](exporting.md) into a
plotting tool instead.

## Is there a GUI

A browser build exists with the same engine; these docs cover the
terminal build. Both share the syntax in
[expression syntax](expressions.md).
