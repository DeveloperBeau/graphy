# abacus

abacus is a desk calculator for the terminal with sensible precision,
readline editing and a persistent history tape.

## Where to start

New users should read [getting started](getting-started.md) first, then
the [expression syntax](expressions.md). The remaining chapters are
reference material:

- [built-in functions](functions.md)
- [memory registers](memory.md)
- [the history tape](history.md)
- [precision and rounding](precision.md)
- [scripting abacus](scripting.md)
- [keyboard editing](keyboard.md)
- [exporting the tape](exporting.md)

If something looks wrong, check [troubleshooting](troubleshooting.md)
before filing a bug, and see the [release notes](releases.md) for what
changed recently.
