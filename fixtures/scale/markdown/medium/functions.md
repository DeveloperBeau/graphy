# Built-in functions

All functions take parenthesised arguments: `sqrt(2)`, `log(100, 10)`.
Each has its own reference page; the first few are linked below and the
pages chain onward from there.

## Arithmetic helpers

[abs](fn-abs.md), [round](fn-round.md), [floor](fn-floor.md) and
[ceil](fn-ceil.md) behave as you would expect, and
honour the current precision described in
[precision and rounding](precision.md).

## Trigonometry

[sin](fn-sin.md), [cos](fn-cos.md) and [tan](fn-tan.md) respect the
angle mode shown in the prompt; inverse forms are prefixed with `a`.

For defining your own functions, see [scripting abacus](scripting.md).
