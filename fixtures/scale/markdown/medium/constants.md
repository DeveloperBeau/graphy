# Constants

`pi`, `e`, `phi` and a dozen physical constants are predefined.

## Using constants

Constants behave like read-only variables in the
[expression syntax](expressions.md): `2 * pi * r` works as written.

## Precision

Constants carry the full twenty internal digits, so displayed values
follow [precision and rounding](precision.md). Physical constants use
the 2018 adjustment values; sources are listed in the
[glossary](glossary.md).
