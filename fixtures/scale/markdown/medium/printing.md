# Printing the tape

A monospaced print of the tape is sometimes the fastest way to check a
long calculation by hand.

## The print command

`print` renders the last screenful; `print all` renders everything the
[history tape](history.md) holds.

## Formatting

Columns align on the decimal point, using the display precision from
[precision and rounding](precision.md). Very long expressions wrap with
a hanging indent.
