# Square parameters

The parameter set the harness registers for Square, as used by every
nightly run.

## Square key sizes

The suite measures the reference key size only; alternate sizes are
noted in the descriptor but not benchmarked.

## Square workload shape

Buffers and pass counts follow the shared rules in
[how runs work](methodology.md); nothing is tuned per cipher. Results
land on the [results page](square-results.md).
