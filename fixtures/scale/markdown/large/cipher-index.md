# Cipher index

Sixty cipher families, each with an overview chapter plus parameter and
result pages.

## By kind

The [block cipher index](block-index.md) lists the forty-four block
entries and the [stream cipher index](stream-index.md) the sixteen
stream entries.

## Starting points

[AES](aes.md) is the baseline every other entry is judged against;
[ChaCha20](chacha20.md) is the software stream benchmark. Measurement
rules for every chapter are set out in [how runs work](methodology.md).
