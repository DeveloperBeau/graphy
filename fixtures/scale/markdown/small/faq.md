# FAQ

Short answers to the questions that reach the mailing list most often.

## Is there a Windows build

Not yet; the terminal handling assumes a POSIX tty.

## Does it slow pipes down

No measurable cost below a hundred thousand lines a second on a laptop.

## Can presets be edited

Not in place, but a rules file from [colour rules](colour-rules.md)
overrides any preset line, as described in [everyday usage](usage.md).
