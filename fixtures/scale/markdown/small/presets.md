# Built-in presets

Six presets ship with inkroll, tuned on real build and server logs.

## The build preset

Warnings in yellow, errors in red, file paths underlined. Most compiler
output looks right with no further configuration.

## The server preset

Timestamps dimmed and status codes coloured by class. Pair it with the
patterns from [colour rules](colour-rules.md) for app-specific fields,
and see [piping patterns](piping.md) for a journalctl example.
